# knowledge-engine-data-base

Base de conocimiento estructurada a partir de un archivo JSON, diseñada como fuente de datos para el motor principal **[knowledge-engine](https://github.com/qbreis/knowledge-engine)**.

Este repositorio contiene:
- El dataset y definiciones de conocimiento en formato JSON.
- La estructura de datos e información base consumida por el motor.

---
*Para ver la implementación y ejecución del motor de conocimiento, consulta el repositorio principal: [qbreis/knowledge-engine](https://github.com/qbreis/knowledge-engine).*
